# ADR 0079: Inter-match-gap recurrence and public language admission close separately

- Date: 2026-08-16
- Status: accepted under `INTER-MATCH-GAP-CAPTURE.7.0`
- Tags: architecture, capture, segmentation, recurring-gate, public-no-drift, actionir, documentation, parity

## Context

ADR `0045` owns the lossless-segmentation semantics and compatibility boundary. Neutral plus all six private
runtime routes are complete at 7/2/60, and the rooted driver passes Perl 124, Rust 1, Dart 5, Julia 319, PUC Lua
392, and LuaJIT 392 after the neutral checker. Two rollout rows remain, but they represent different claims:
repeatable repository governance and current public cross-backend language support.

The four implemented gap calls are still staged outside the shared 246-call inventory and classified non-public
by the language checker. The existing no-overclaim contract also guards only one exact sentence in five documents
plus ten outward surfaces. It does not deny stale surrounding prose. Thus correct 7/2 markers coexisted with old
Lua-skip and 3/6 route claims after Lua admission.

## Decision

Close the program in three dependency-complete leaves:

1. `.7.1` admits only recurring topology and advances 7/2/60→8/1/61 with `recurring_regression`.
2. `.7.2` promotes `entry_slot`, `gap_span`, `gap_text`, and `gap_kind` from staged-private to current shared
   language calls. Shared calls move 246→250 and independently derived public Perl contracts 122→126;
   recognition keeps 137 ActionIR rows while its call-effect projection moves 246→250. Public no-drift closes
   at gap 9/0/63 with six documents, twelve stale-current denials, ten outward guards, and 29 public mutations.
3. `.7.3` changes no executable artifact; it recomposes, closes the tree, and hands only typed
   `gap_composition` to `FUTURE-PARITY-BACKLOG.14.5.1`.

Legacy `@capture_slice`, `@capture_from_here`, and `@move_pos` behavior remains retained and is never an alias for
`@capture_gaps`. Named marks and explicit helpers stay independent. `@emit_gaps` and forced AST emission remain
absent. README, facades, outward descriptor/result schemas, semantic/MCP, CLI, capability census, storage,
generated format, and typed-source rollout do not move implicitly.

## Consequences

- Recurrence cannot overclaim language admission, and public documentation cannot hide a missing recurring gate.
- Public call inventories become honest only in the leaf that also teaches and mutation-locks the feature.
- Marker-only documentation governance is replaced by omission-sensitive current/stale/surface proof.
- Typed-source composition consumes one closed authority and does not fork gap syntax or lifecycle.
