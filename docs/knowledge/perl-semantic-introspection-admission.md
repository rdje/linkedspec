# Perl Semantic Introspection Admission

Perl is the first admitted implementation of `linkedspec-semantic-model-v1` and
`linkedspec-semantic-query-v1`. Admission does not introduce another model, projector, query evaluator, observer,
or transport. The composed consumer calls the existing opaque constructor, static and call/staged/generated
projections, public immutable evaluator, and caller-owned runtime derivation.

Its 12 contract-declared roles execute exactly once:

- strict UTF-8 bytes and decoded text normalize to one response;
- compiled graph/calls/privacy, failed-compilation, and derived runtime snapshots are queryable;
- direct, loaded, generated direct, and generated traced observations yield the same runtime digest;
- native capabilities and neutral JSON are identical and clone-safe;
- all 20 canonical responses match their complete SHA-256 digests;
- privacy, page, budget, portable error, and explanation behavior is exact; and
- queries stay silent and executable with compilation disabled, while every response denies host paths, objects,
  backend IR, and generated implementation source.

The neutral checker requires the consumer path, ordered role list, canonical tracked registration and invocation,
Perl admission status, and Perl rollout status. Eight new mutations remove or alter those boundaries, while the
existing early-admission mutation now targets Rust. At that July-21 milestone the totals were 65 rejected mutations, rollout 2 complete / 7
pending, and native admission 1 complete / 5 pending, with Rust `.10.4` next. Those are historical counts.
The September 6 `.3.2.41` reading checkpoint reruns the current neutral checker: six fixture groups, twenty
exact queries, 128 rejected mutations, 9/9 rollout, and 6/6 native admission are complete. This bounded
checkpoint does not rerun every runtime admission consumer.
