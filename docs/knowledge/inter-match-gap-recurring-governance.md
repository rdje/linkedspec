# Inter-match gap recurring governance

`tools/check_inter_match_gap_capture_six_runtime.sh` is the one ordered recurring driver. It derives
`REPO_ROOT` from its own path, enters `tools/project_data_env.sh`, and runs
`bash tools/run_python_project_data.sh tools/check_inter_match_gap_capture_contract.py` exactly once. It then runs
the admitted Perl, Rust, Dart, Julia, PUC Lua, and LuaJIT consumers exactly once each in contract order.

Perl's full 124-test final-path consumer passes authored/static, native-live, emitted/loaded, lifecycle,
rollback/recursion, and typed-diagnostic roles. Rust, Dart, Julia, and shared Lua each execute the exact declared
nine-role native/carrier/emitted/primary ledger. Ten Rust, ten Dart, ten Julia, and sixteen Lua admission
mutations lock consumer identity, roles, ordinary/canonical/rooted multiplicity, order, and facade absence.

Canonical `tools/run_ci_local.sh` always executes the neutral checker. Setting
`LINKEDSPEC_RUN_INTER_MATCH_GAP_MATRIX=1` additionally invokes the ordered driver. This switch proves neutral plus
all six runtimes, route order, and repository-volume storage. Recurring is current under `.7.1`, and public
language/no-drift is current under `.7.2`; neither claims facade/schema, capability, CLI, or README exposure.

The format-1 contract fixes the neutral-plus-six route order, current recurring/public status, storage initializer,
managed entrypoint, canonical switch, six exact documentation markers, twelve stale-current denials, and ten
guarded outward facade/schema/CLI/README paths. Those outward paths continue to reject `@capture_gaps`,
`entry_slot`, `gap_span`, `gap_text`, `gap_kind`, `Rule[name]`, and `name=/regex/`: public language admission does
not imply facade/schema admission. The current reason-checked set is 63 semantic mutations plus 29 public
mutations and ten Rust, ten Dart, ten Julia, and sixteen Lua admission mutations, with rollout 9 complete + 0
pending.
