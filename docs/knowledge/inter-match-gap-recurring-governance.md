# Inter-match gap recurring governance

`tools/check_inter_match_gap_capture_six_runtime.sh` is the one ordered recurring driver. It derives
`REPO_ROOT` from its own path, enters `tools/project_data_env.sh`, and runs
`bash tools/run_python_project_data.sh tools/check_inter_match_gap_capture_contract.py` exactly once. It then runs
the admitted Perl and Rust consumers once each and reports—but does not invoke—the exact pending Dart, Julia,
PUC Lua, and LuaJIT consumer routes.

Perl's full 124-test final-path consumer now passes authored/static, native-live, emitted/loaded, lifecycle,
rollback/recursion, and typed-diagnostic roles. `.2.4` registers it once in ordinary canonical execution and once
in this rooted route. Rust's exact nine-role consumer adds native/reconstructed/descriptor/generated/emitted,
lifecycle, recursion/rollback, diagnostic, and primary-command proof; `.3.5` registers it once on both routes.
Perl and Rust regressions are independently rejected. The final Dart consumer now exists but remains
library-skipped and absent from both execution routes; ten Dart dormancy mutations lock that boundary. Four later
runtime routes remain pending and the public facade remains guarded.

Canonical `tools/run_ci_local.sh` always executes the neutral checker. Setting
`LINKEDSPEC_RUN_INTER_MATCH_GAP_MATRIX=1` additionally invokes the ordered driver. This switch currently proves
neutral plus private Perl and Rust support, route order, and repository-volume storage; it does not claim later backends or
public support. Runtime admissions remain owned by `INTER-MATCH-GAP-CAPTURE.3-.6`; `.7` alone can promote
`recurring` and `public_no_drift` after all six runtime proofs exist.

The format-1 contract fixes the neutral-plus-six route order, pending runtime statuses, storage initializer,
managed entrypoint, canonical switch, five exact documentation markers, and ten guarded outward
facade/schema/CLI/README paths. Those outward paths reject the planned `@capture_gaps`, `entry_slot`, `gap_span`,
`gap_text`, `gap_kind`, `Rule[name]`, and `name=/regex/` tokens until public admission. The current reason-checked
set is 56 semantic mutations plus ten Rust admission and ten Dart dormancy mutations, with rollout 3 complete +
6 pending.
