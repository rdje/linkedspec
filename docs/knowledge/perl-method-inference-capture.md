resolution in _infer_assignment_source_container_kind, _lower_value_binding_source_expr
and _lower_typed_declare_statement, in addition to the three trim callers documented
in docs/knowledge/perl-method-trim-capture.md. The new three resolvers account for
eight actual callback roles: trim, method parse and argument normalize in container
inference; trim and assignment-source lowering in value binding; declaration split,
binding parse and initializer lowering in the retained declaration helper.

Public maps keep actual callback references. Each private binding invokes that
actual reference through its own SourceEmissions boundary when the channel is
already loaded. Opaque and known child callbacks cannot donate their publication
to a parent capture; a known child's own identity remains eligible. Wrapping the
actual callback in a new CODE before binding loses that identity even when all
ordinary values match. Nine effective syntax-valid faults independently remove
each boundary, substitute that wrapper and remove required diagnostic validation.
