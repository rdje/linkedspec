# Recurring typed source-location gate

The recurring layer is orchestration over the six admitted runtimes, not another source-location representation.
Each consumer remains the authority for immutable positions, direct spans, derived-text provenance, Unicode-scalar
coordinates, exact helper projections, aliases, diagnostics, privacy, and unchanged native/generated execution.

The source/runtime cardinality is intentionally asymmetric. Perl contributes separate immutable-value and helper-
projection consumers. Rust, Dart, and Julia each contribute one combined consumer. Lua contributes one shared
consumer source that executes independently on PUC Lua and LuaJIT. Those five backend groups therefore form six
ordered runtime routes after the neutral checker.

Canonical CI requires, path-audits, and syntax-checks the driver on every run. The expensive all-toolchain route is
explicitly opt-in through `LINKEDSPEC_RUN_TYPED_SOURCE_MATRIX=1`. The driver then checks generated-source,
capability, and language-coverage ledgers so a runtime admission cannot silently drift away from the surrounding
support authorities. It creates no private temporary root; the existing project-data initializer derives scratch
from the repository.

Eleven mutations independently reject missing consumer groups or paths, missing/reordered/duplicated runtime
routes, command drift, incorrect source binding, missing support checks, driver or CI-switch drift, and premature
completion of the combined final row. The executable ledger consequently stays at 8 complete / 6 pending while
the mutation count advances to 53. `FUTURE-PARITY-BACKLOG.14.8` still owns authored public values, transactions,
observations, progressive/staged dispatch examples and tooling, and final public no-drift.
