# Perl progressive span-dispatch admission

Private Perl progressive span dispatch is canonically admitted. The admission
does not change its syntax, runtime, generated carriers, or host authority; it
originally routed the already-green final-path consumer and advanced only the Perl
rollout row. Later owned admissions and closeout completed every progressive row;
the neutral contract now enforces 9/9 with 116 contract mutations and the separate
public 6/12/10/60 boundary.

The recognition effect inventory now includes `PROGRESSIVE_DISPATCH_SPAN` as
the only current `parser_registry_or_staged_dispatch` node. It remains rejected
inside uncommitted recognition and has no canonical call row. This raises the
current ActionIR census to 134 plus four dedicated transaction nodes.

`dispatch_span` remains outside the shared public-call inventory. Perl owns it
as a dedicated intrinsic. At the original Perl-only admission, removing the exclusion
would have claimed unsupported shared-helper parity. Six-runtime recurrence and
public closeout are now complete and deliberately preserve that exclusion: private
intrinsic support does not add a shared public helper or outward API. See
[[progressive-span-dispatch-public-no-drift]] for the final boundary.
