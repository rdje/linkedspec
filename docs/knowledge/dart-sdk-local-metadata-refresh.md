# Dart SDK and project-local metadata alignment

`dart test` may wait inside the Dart event loop without starting a test when ignored `.dart_tool` compiler/test
metadata was generated by an older SDK. A fast `dart --version` does not exclude this state because the SDK
binary itself is healthy; compare it with `dart/.dart_tool/package_config.json`'s `generatorVersion`.

The mutation recurring driver prevents this stale-state wait by running `dart pub get --offline` through the
repository-routed Dart wrapper before either permanent Dart consumer. The lockfile remains authoritative, the
package cache and generated metadata remain on the repository filesystem, and no network fallback is allowed.
