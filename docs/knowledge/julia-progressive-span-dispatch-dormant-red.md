an ordinary `ActionCallExpr`. Runtime helper resolution rejected `dispatch_span` with the existing
unsupported-helper boundary; that consistent failure was not child-parser execution. Rebuilding the parsed
`SpecFile` from JSON, executing its validated generated-v2 plan, and independently including a freshly emitted
module preserved the same outcome.

The historical emitted module reconstructed and compiled the same normalized spec before entering the shared
runtime. Its generated failure recorded the emitted source identity, `execute_generated` stage,
`generated_execution_failed` code, `Top` rule, `default` family, and the same unsupported-helper detail. The
generated source contained no progressive authority, registry, or dedicated-node token.

discovery, and had 55 GREEN assertions with only the dedicated-node assertion RED. `.14.6.5.2` preserved the
fixture and dormant boundary while making all seven groups GREEN at 62 assertions; `.14.6.5.3` then moved that
same proof into ordinary/canonical discovery without changing behavior.
