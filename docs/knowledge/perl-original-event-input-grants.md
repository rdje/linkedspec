# An actual event selects the original input frame

MethodExpr input collectors under the actual current SourceOrigins invocation
token. An opaque scalar-reference grant selects only a retained actual event or
actual capture/callback/node/argument-array/index and its retained parent grant.
Public fields, detached descriptions and equal text do not select an occurrence.

authored Unicode/CRLF/twin/omitted-slot/array/nested/empty oracles and actual
scanner→Diagnostics→CanonicalEvents handoff retain original character intervals.

actual native capture data. Copied, changed, foreign, nested or expired objects
cannot borrow grants. Changed AST ancestors revoke dependent grants; a changed
MethodExpr value revokes its indexed grant while its unchanged neighbor retains
its own frame. Descriptions remain detached. Scope exit releases the registry.

belonging to that actual builder event. Invalid or transformed input appends
ordinary generated text. `_consume_input` records only that valid original child
interval. Duplicate source copies remain separate; consuming one argument does
not consume the whole event or its equal neighbor. Existing emission APIs retain
their prior behavior. Scalar once-only callbacks, aliases, actual result and fatal
