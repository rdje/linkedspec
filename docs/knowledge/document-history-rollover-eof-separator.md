# A record separator becomes a terminal blank line

The governed writer at tools/roll_document_history.pl:94 constructs the retained
hot root by joining complete record strings. When the final retained record ends
with a blank separator, the new root has two terminal LF bytes. Git diff --check
then reports new blank line at EOF. This is not archive corruption: the exact
source suffix and every older immutable manifest row remain unchanged.

The current slice retains the entire generated root losslessly in its
history-rolled-root.json before removing exactly one LF from mutable CHANGES.
The reviewer requires final_root plus that LF to equal the complete retained
generated bytes and reconstructs the exact original clean root with the archive.
Neither archive nor manifest bytes are normalized. Actual whitespace commands
retain original RED and final GREEN stdout/stderr/exits.
