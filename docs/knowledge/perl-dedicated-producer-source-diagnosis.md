RecognitionTransactionRules: one staged annotation, one progressive annotation,
recursive observation and four transaction forms. At that immutable original boundary these scanners use the ordinary statement
split callback and return their dedicated events without invoking the private
source recorder. Staged payload provenance describes parsed input text;
it does not supply the authored action statement's event origin.

The canonical splitter already supplies exact physical statement frames. Independent
authored segment boundaries distinguish repeated equal annotations and quoted-only
controls. The diagnosis retains complete original literal arguments, including
normalized staged text plans/options and malformed dedicated operands. Static policy
must continue to see those invalid events so it can reject them.

The recorder repair is split into staged .1.5.1, progressive .1.5.2 and recognition/
observation .1.5.3, followed by independent canonical family acceptance .1.5.4.
Each implementation must preserve the original split/trim/parser callback sequence,
returned event/argument identity, exclusive ownership and static validation. Unknown,
copied, changed or foreign callback source cannot authorize invented coordinates.

The measured identities are captured at the actual family dispatcher return:
array, event and argument objects survive the public/private wrapper unchanged.
They are not an observation of every intermediate constructor object. The four
Toolbox channels cover substitution, descriptor ActionIR metadata, successful

those four parsers. The selected existing consumers separately exercise runtime
behavior. Three sampled seeds do not prove arbitrary callbacks or host syntax.

Full supplied inputs are a conservative Git superset, not minimal observed I/O.
Submodules and nonregular metadata are excluded without payload reads. All scratch
and outputs remain on the parent repository volume; OS/toolchain prerequisites are
necessary read-only inputs. The claim binds actual producers and artifact inputs.
