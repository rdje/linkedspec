MethodLowering's private _bind_emission_dependency retains the actual callback in
a lexical thunk. It forwards original argument aliases and native scalar/list/void
context to SourceEmissions::_invoke_emission_dependency when already loaded, and
calls the original callback directly otherwise. Caller maps and public callback
fields keep their actual references; no private channel is eagerly required.
Native return/reference/undefined/list values, once-only effects, incoming and
successful error effects, and fatal object identities remain exact in the bounded
fifteen direct-native/current-binding observations. A lexical callback remains
alive while bound and is released with the binding; no global cache is added.

At the trim-boundary acceptance, three required return seams spend this binding:
_infer_direct_shape_literal_kind, _normalize_method_tag_expr and
_lower_inline_switch_case_value_expr. Their actual trim calls are scalar, and
existing top-level local argument copies remain intact. Nine actual caller modes
compare string, undefined and fatal outcomes. The shape owner's secondary
_lower_method_value_expr result is explicitly held constant while probing its
actual trim invocation; this proves the boundary without admitting all successful
shape/value behavior. Bare inline switch-case normalization retains two trim calls.
Required missing/non-CODE callbacks keep their original diagnostic prefix.
