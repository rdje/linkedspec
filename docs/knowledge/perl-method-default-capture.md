MethodLowering::default_deps_for_package keeps the actual OwnerDispatch map and
its original public callback references. Only the built-in EmitContext target
can select defaults, and each actual callback must match the separate method
catalogue of definition-owned native references retained when EmitContext loads.
The dated population is nineteen callbacks, derived and checked against the
original clean-Git default factory and complete native/current map ledgers.

Replacing a public native name preserves the replacement in the returned map
and leaves it opaque. The retained original native CODE reference still selects
through the private definition-owned selector. A custom target aliasing the actual
native callbacks preserves those public references but cannot register them
through this factory. Already selected actual callbacks retain their own identity;
later name replacement neither revokes that identity nor grants it to a replacement.
Every same-name opaque callback actually attempts publication and returns equal
text in the fixture; the ordinary value survives and no selected packet results.

Selection uses the existing actual source/producer registry. A nested equal-source
or producer scope cannot borrow enclosing registration; exit restores the actual
enclosing selection. Factory calls outside an eligible scope grant no authority
and create no global scope. Cold defaults load neither SourceEmissions nor Trace.
The native facade references remain module-owned: this slice makes no universal
weak-reference release or native helper packet-production claim.

Initial runtime/native/inverse/consumer captures were all GREEN. Their inverse
scope description incorrectly retained constructor terminology from the prior
instrument. All30 original captures and exact producer remain tracked. The readonly
review reconstructs the prose/console-only correction and verifies unchanged
runtime inputs and actual recapture. No production or fixture change followed that
correction, and no original runtime failure is invented or hidden.
