## Existing authority and actual gap

call(RuleName) invokes the existing child handler and returns its value. Existing
static rule-label/arity/lookup, child frame/cursor/retv/accumulator/error behavior
and parser-state function restrictions remain authoritative. This is not a new
invocation API, dynamic rule-name feature, implicit child push or shared scope.

At2b3135fa2, six finite native/fresh controls already pass: primitive Array/Hash,
bound Array/Hash reads, Array last/String methods and String split/index/method.
Direct call(Child)[-1] and call(Child)["name"] instead fail handler/fresh-source
compilation, raw1/unready. MethodLowering already owns the rule-call value ABI;
AST Parser's computed-call source predicate admits data helpers/registered
functions and boxed context collections, but excludes rule calls. Preserve the
legacy bound-codeblock reader, metadata/count/coercion and deferred grammar.

## Bounded additive target

- Existing ordinary call(RuleName) results feed the current Array/Hash rvalue
  bracket machinery, then further brackets and compatible fluent methods.
  Begin the established single static word-label spelling; no new dynamic,
  quoted, optional-scope, argument, Unicode-label or arity policy is adopted.
- Reuse zero-based/signed Array positions and literal String Hash keys. Preserve
  selected Bool/Number/String/null/Array/Hash kinds. Wrong source kinds, missing
  keys and out-of-range positions return null; this adds no String character
  indexing, key coercion, dynamic Hash key or new selector domain.
- Invoke the child once before selector expressions, then evaluate selectors
  left to right once, including after a missing path, before compatible consumer
  operands. Materialize the returned value before later selector/operand effects.
  Preserve existing snapshots/copy depth, source errors and consumer guards.
- Keep named-read lookup, computed-write rejection, preflight/error-phase,
  callable/function/callback/deferred provenance and source/span/AST/schema/
  generated-format contracts. Reuse the existing value_access representation.
  Full source/domain/context/portable23.4 remains separate.
