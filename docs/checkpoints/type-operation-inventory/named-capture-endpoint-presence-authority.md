Owner: TYPE-REFERENCE-BOOK.1.2.23.3.47.0; independent children47.1-.5.

This target composes ADR0056 source/span/absence, anonymous40 local-match presence,
the existing named-span undef/valid-only-take contract, named34/42 String word-name
argument authority and42.5 reversal guards. No new public helper, alias, writer,
key grammar, diagnostic/schema, cursor policy or mark-frame architecture is granted.

- capture_from(name), capture_len_from(name), capture_take(name) and
  capture_take_len_from(name) require an existing named origin and an available
  current local-match left edge, in source order. Missing endpoint or reversed
  span yields undef without manufacturing a typed interval or host arithmetic.
- Accepted names finish once before mark reads, with existing symbolic bare names
  and actual String word-name expressions. Their authored effects still occur
  when the eventual endpoint is absent. Argument-local returns remain local;
  this does not widen domains/static arities or peer invalid-name policies.
- A failed take performs no extra mark/boundary mutation. Its name expression's
  own effects remain. A successful match-start named take advances its named
  origin to the live cursor, independently of the local match's left edge.
- capture_take(name) is the existing named text overload: read/advance that mark,
  leave the anonymous boundary alone. capture_take() remains anonymous. No new
  named capture_take_len spelling or alias is inferred; named width uses the
  existing capture_take_len_from(name).
- Real empty/zero matches are present. Empty text and width0 remain defined and
  skip coalesce defaults; zero after a Unicode prefix can capture the prefix.
- Missing marks remain missing, including failed takes. Reversed named spans
  return undef/no extra advance. Through-cursor, rest and between families use
  their own available endpoints and retain their existing movement/mark behavior.
  Available mark_here/input/capture writers and anonymous origins stay independent.
- Preserve existing rule-label buckets, calling/function/deferred vocabulary and
  context ownership; frame migration/wider keys/readiness/admission remain separate.
