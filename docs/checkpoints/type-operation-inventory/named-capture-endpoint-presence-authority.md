- capture_take(name) is the existing named text overload: read/advance that mark,

  existing capture_take_len_from(name).

  skip coalesce defaults; zero after a Unicode prefix can capture the prefix.
- Missing marks remain missing, including failed takes. Reversed named spans
  return undef/no extra advance. Through-cursor, rest and between families use
  their own available endpoints and retain their existing movement/mark behavior.
  Available mark_here/input/capture writers and anonymous origins stay independent.
- Preserve existing rule-label buckets, calling/function/deferred vocabulary and
  context ownership; frame migration/wider keys/readiness/admission remain separate.
