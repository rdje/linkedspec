A dated retention review can also reuse a clean Git input without copying its full packet. Compare the actual index stream with the exact mode/object/path inverse of the retained base tree before interpreting it, and preserve byte identity plus an altered-input RED control. This proves logical input recovery; it does not establish physical index, native-tool or filesystem custody, and a metadata census grants no deletion authority.

Historical recovery readers should bind task status, frontier and resume-pointer checks to the accepted input epoch. Later pointer movement can invalidate an old live boundary without invalidating the earlier plan. Make that current-boundary check explicit and keep it separate from default historical recovery.
