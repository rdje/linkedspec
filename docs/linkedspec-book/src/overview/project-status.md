# Project Status

LinkedSpec is an actively evolving system.

The current direction is not “freeze everything exactly as it once was.” The direction is:

- preserve the strengths that make LinkedSpec useful
- modernize the runtime and compiler seams
- improve diagnostics and trust
- clarify naming and architecture
- and move the action story toward a backend-neutral model

## What that means for readers

- Some older historical names still appear in repo history and older notes.
- The active code path is being cleaned up toward clearer terms and clearer state models.
- The current public and architectural explanations should prefer the active surfaces, not the oldest historical vocabulary.

For the live implementation status, the roadmap and architecture docs in the repo remain the fastest changing references. This book should absorb that understanding over time in a more stable, explanatory form.
